# Dispatch Logs

Timestamped session logs created automatically by `vault-writeback.sh` when Claude Code stops.

## Format

Each file is named `YYYY-MM-DD_HH-MM.md` and contains:
- Files modified during the session (from `git status`)
- Brief notes on what was done
- A section for learnings (fill in manually)

## Usage

After a session, open the latest log and:
1. Add a one-line summary of what was accomplished
2. Note any decisions made that aren't captured in code
3. If a pattern is worth keeping across future sessions, move it to `memory/learnings/`
